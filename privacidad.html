Política de Privacidad

Última actualización: Junio 2026

1. Introducción

En Agenda TrackSIM, valoramos y respetamos tu privacidad. Esta Política de Privacidad explica cómo recopilamos, utilizamos y compartimos información sobre ti, así como los permisos que solicitamos al interactuar con nuestra plataforma y servicios de terceros, incluyendo las API de Google.

2. Uso de Datos de Google (Google API Services)

Nuestra aplicación hace uso de la integración con Google Calendar API para sincronizar los eventos y reservas de la agenda directamente con tu calendario personal o de trabajo. Para proporcionar esta funcionalidad, solicitamos los siguientes permisos (scopes):

  • https://www.googleapis.com/auth/calendar
  • https://www.googleapis.com/auth/calendar.events

2.1. ¿Qué datos de Google recopilamos y cómo los utilizamos?

  • Creación y Modificación de Eventos: Usamos la API de Google para crear un calendario llamado "Agenda TrackSIM" y para insertar, leer y actualizar eventos (reservas) en dicho calendario.
  • Almacenamiento: Solo guardamos en nuestra base de datos (Firebase) el identificador único del evento de Google (googleEventId) para evitar crear eventos duplicados en futuras sincronizaciones.
  • Restricciones de Uso: El uso que hace Agenda TrackSIM de la información recibida de las API de Google cumple estrictamente con la Política de datos de usuario de los servicios API de Google, incluidos los requisitos de uso limitado. Los datos de Google Calendar no se comparten con terceros, no se venden, y solo se utilizan para proporcionar la funcionalidad de sincronización de la agenda a nuestros administradores autorizados.

3. Datos proporcionados por el usuario

Al utilizar nuestra aplicación, podemos solicitar información como: nombre de cliente, direcciones y datos de contacto para gestionar las reservas. Esta información se almacena de manera segura en nuestra infraestructura proporcionada por Google Firebase y solo tienen acceso los administradores autorizados (ej. magraz@corporativomaf.com).

4. Compartir Información

No compartimos, vendemos, ni alquilamos tu información personal a terceros. El acceso a la plataforma está estrictamente limitado a personal administrativo autorizado de TrackSIM.

5. Seguridad

Implementamos medidas de seguridad estándar de la industria (incluyendo la infraestructura de seguridad de Firebase y Google Cloud) para proteger la información contra acceso no autorizado, alteración, divulgación o destrucción.
